# Travel Planner

A modern web app for planning trips with friends — create a trip, invite the group, and organize everything (itinerary, flights, packing, expenses, and more) in one place.

Built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
